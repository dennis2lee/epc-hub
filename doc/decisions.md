# 결정 기록

결정마다 날짜, 내용, 이유, 근거(누가·무엇으로 정했는지)를 남긴다. 사용자가 직접 답할 수 없는 항목은 개발 담당이 Fable 자문을 받아 정하고 "잠정"으로 표시한다. 잠정 결정은 당회·재정부 확인 후 바꿀 수 있다.

## 업무 규칙 (2026-11-21, 사용자 확정)

| # | 결정 |
|---|---|
| A1 | 결재는 지출 부서의 부장과 담당 장로만 한다. 재정부는 서명하지 않는다 |
| A2 | 금액에 따른 추가 결재는 없다 |
| A3 | 보완 요청 후 다시 제출하면 부장부터 다시 받는다 |
| A4 | 모든 부서에 담당 장로가 있다. 비어 있으면 제출을 막는다 |
| A5 | 관리자는 사무간사와 개발 담당. 처음에는 이평우 1명. 감사는 감사위원 |
| A6 | 부장 본인 청구는 담당 장로 한 명이 결재하고 '결재자 1인'으로 표시 |
| A7 | 담당 장로 본인 청구는 부장 한 명이 결재하고 '결재자 1인'으로 표시 |
| A8 | 재정부는 서류 보완을 요청할 수 있다. 사유 필수, 부장부터 다시 |
| A9 | 재정부원이 한 명뿐이면 그 사람의 본인 청구는 재정 담당 장로가 확인·지급 |
| U1 | 교회는 미국에 있다. 금액은 USD, 교인 휴대폰은 대부분 +1 |
| U2 | 지급은 수표로만 한다 |
| U3 | 교회 카드 결제는 현재 버전에서 시스템에 올리지 않는다 (나중에 바뀔 수 있음) |

## 구현 결정

구현 착수 시점의 결정은 아래 "구현 결정 (잠정)"에 이어서 적는다.
