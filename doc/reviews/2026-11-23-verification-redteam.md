# 구현 검증 레드팀 (전체 코드)

- 날짜: 2026-11-23
- 범위: 화면·서버 코드, DB 마이그레이션, 운영 스크립트, 설계서·구조 보고서와의 일치
- 방식: 정적 분석 위주. 검증을 통과한 발견 3건, 근거를 두고 기각한 후보 8건
- 관련 결정: D50, D51

## 검증

- DB(pgTAP) 155건 통과. 새 파일 `05_pending_drafts_test.sql` 12건: 대기 계정의 저장·본인 청구 읽기·제출 거부·부서 목록·다른 교인·직책·설정·결재선 차단, 다른 교인에게 임시저장이 보이지 않음.
- 단위 51건(마이그레이션 호환 검사 포함), 통합 8건, E2E 7건 통과. 새 E2E `pending-draft.spec.ts`: 결재 관계자로 등록 → 초대 링크 연결 → 대기 안내 → 임시저장·영수증 올리기·영수증 열기 → 결재 올리기 비활성 → 대면 확인 완료 → 결재 순서 표시.
- 린트, 타입 검사, 운영 빌드 통과.

## 남은 확인

- `notify pgrst`의 실제 효과는 맥미니의 self-hosted 스택에서 첫 배포 때 확인한다. 로컬에서는 명령이 성공하는 것만 확인했다.

## 재검증 후 잔여 2건과 조치

| # | 심각도 | 발견 | 조치 |
|---|---|---|---|
| R1 | 낮음 | `migrations.test.ts`가 열 형식 변경(`alter column … type`)과 기존 함수에 대한 `revoke`를 잡지 못한다. 둘 다 배포 중 이전 앱을 깰 수 있다 | 두 패턴을 추가했다. 권한 회수는 앞선 마이그레이션들이 만든 함수·테이블을 모아 두고, 그 대상에서 `public`·`anon`이 아닌 역할의 권한을 빼거나 스키마 전체 함수·테이블에서 빼면 실패로 본다. 새로 만든 함수의 권한 정리(`public`·`anon`에서 회수)는 통과한다. 판별 사례 20개를 테스트에 넣었다 |
| R2 | 낮음 | 대기 계정 E2E가 CI에서 돌지 않는다. 화면 회귀는 로컬 실행에 의존한다 | CI의 `database` 작업에서 pgTAP·통합 테스트 뒤 Playwright E2E 7건을 같은 로컬 스택으로 돌린다. 실패하면 보고서를 7일 보관한다 |
| 기타 | 사소 | 구조 보고서의 마이그레이션 수가 12개(실제 13개) | 저장소 구성 표의 파일 수·줄 수를 모두 다시 셌다 |
| R3 | 중간 | (R2를 CI에서 돌리며 발견) 폭 360px 휴대폰에서 작성 화면이 433px로 넓어져 가로로 밀린다. 금액 입력 칸의 고유 폭과 grid·flex 자식의 최소 폭 때문이다. 확인 창이 열리면 탭이 엉뚱한 요소에 닿는다. CI의 리눅스 글꼴에서는 412px에서도 생겨 E2E 4건이 실패했다 | `.stack`·`.field`·`.line-row`·`.btn-row`·`.row-link` 자식에 `min-width: 0`, 입력 칸 `width: 100%`, 긴 문자열 줄바꿈. 버튼의 한국어는 낱말 단위로 줄바꿈(`keep-all`). E2E `layout.spec.ts`가 360px에서 관리자·홈·작성·확인 창·재정 화면의 가로 넘침을 검사한다. CI는 안드로이드와 같은 Noto CJK 글꼴을 설치해 돌린다 |

## 3차 재검증 후 조치

| # | 심각도 | 발견 | 조치 |
|---|---|---|---|
| R1-2 | 낮음 | 이름 추출이 괄호를 요구해 `revoke execute on function public.f from …`(인자 목록 없음, PostgreSQL 허용)가 통과한다. 뷰·시퀀스 회수, `$$` 본문 속 문장은 구조적 한계 | 대상 목록을 최상위 쉼표로 나눠 각 항목의 앞 식별자를 이름으로 쓴다(인자 목록 선택). 앞선 마이그레이션이 만든 뷰·구체화 뷰·시퀀스·프로시저도 모아 `on sequence`·뷰 대상 회수를 잡는다. `revoke`를 문장 맨 앞이 아니어도 찾는다. 확인해 보니 `$$` 본문 안에 적은 문장은 원래 검사되고 있었다(전체를 `;`로 나누므로). 이를 판별 사례로 고정했다. 남은 한계는 실행 중에 조립하는 SQL(`format()`, `||`) 하나이고, D51과 `deploy.md`에 금지로 적었다. 판별 사례 29건 |
