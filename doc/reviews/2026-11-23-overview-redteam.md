# 구조 보고서 레드팀 검토 (`doc/overview.html`)

- 날짜: 2026-11-23
- 검토자: Fable 레드팀 1개 (문서와 코드 대조, 파일 수정 없음)
- 대상: `doc/overview.html` 초안 (4단계 구조 보고서, 사용자 관점 포함)
- 관련 결정: D48 (프로젝트 이름 epc-hub, 저장소 공개, 문서 사이트)

## 요약

표지 숫자(화면 9 · 라우트 9, 테이블 20, 함수 101, 테스트 205, 결정 59, 레드팀 5)는 모두 맞았다. 문제는 세 가지였다.
- 구현되지 않은 기능을 있는 것처럼 썼다.
- 당회가 약속으로 읽을 수 있는 표현이 있었다.
- 그림 2·3·4의 화살표가 실제 구조와 달랐다.

19건 모두 반영했다(일부는 판단을 달리함, 아래 표).
