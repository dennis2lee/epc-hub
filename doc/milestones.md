# 마일스톤

| # | 이름 | 끝에 동작해야 하는 것 | 상태 |
|---|---|---|---|
| M0 | 기반 + 카카오 시험판 | 로컬에서 이메일 코드 로그인 → 원래 경로 복귀 → 파일 업로드 → CSV 받기. 카카오 1·2안은 키만 넣으면 동작. pgTAP과 Vitest가 통과 | 완료. 카카오 실기기 시험은 운영 서버 설치 후 |

| M2 | 작성·결재 화면 | 초대·연결, 작성, 영수증, 제출, 승인·보완 요청, 다시 제출, 홈 목록. 휴대폰 브라우저에서 세 계정으로 승인까지 | 완료 |
| M3 | 재정·알림·문서 | 서류 확인·보완 요청, 수표 기록(여러 건 묶음), 알림 메일, 막힌 건 목록과 Cron, 인쇄본, 월별 CSV | 완료 |
| M4 | 시범 준비 | Playwright 핵심 경로, 실기기 점검표, 운영 DB 보호, 운영 절차서, 운영 구성 시험 | 진행 중. 운영 구성(교회 맥미니, D41~D49)의 설치·배포·백업·복원을 개발용 맥에서 시험 통과. 남은 것: 맥미니 구입·설치, Cloudflare·Resend·카카오 연결, 실기기 점검 |
