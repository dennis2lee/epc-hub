# 마일스톤

각 마일스톤이 끝나면 Fable 레드팀 검토를 하고 결과와 조치를 `doc/reviews/`에 남긴다.

| # | 이름 | 끝에 동작해야 하는 것 | 상태 |
|---|---|---|---|
| M0 | 기반 + 카카오 시험판 | 로컬에서 이메일 코드 로그인 → 원래 경로 복귀 → 파일 업로드 → CSV 받기. 카카오 1·2안은 키만 넣으면 동작. pgTAP과 Vitest가 통과 | 구현 완료, 레드팀 검토 중. 카카오 실기기 시험은 클라우드 환경 준비 후 |
| M1 | DB 핵심 (화면 없음) | 테이블, RLS, 전이 함수, 감사 트리거, 시드. 청구 한 건이 pgTAP에서 작성부터 지급까지 간다. 설계서 12장의 필수 테스트 통과 | 구현 완료(pgTAP 40건), 레드팀 검토 중 |
| M2 | 작성·결재 화면 | 초대·연결, 작성, 영수증, 제출, 승인·보완 요청, 다시 제출, 홈 목록. 휴대폰 브라우저에서 세 계정으로 승인까지 | 예정 |
| M3 | 재정·알림·문서 | 서류 확인·보완 요청, 수표 기록(여러 건 묶음), 알림 메일, 막힌 건 목록과 Cron, 인쇄본, 월별 CSV | 예정 |
| M4 | 시범 준비 | Playwright 핵심 경로, 실기기 점검표, 미리보기 DB 분리, 운영 절차서, 클라우드 배포 리허설 | 예정 |
