# 실기기 점검표

시범 운영 전에 실제 교인 휴대폰으로 한 번씩 확인한다. 자동 테스트(Playwright, Pixel 7 크기 크롬)가 잡지 못하는 것만 모았다. 결과는 표에 O/X와 메모로 적고 `doc/reviews/`에 날짜를 붙여 보관한다.

## 기기

| # | 기기 | 브라우저 | 누가 | 날짜 |
|---|---|---|---|---|
| 1 | 아이폰 (iOS 최신) | 카톡 안 브라우저 | | |
| 2 | 아이폰 | 사파리 | | |
| 3 | 안드로이드 (삼성) | 카톡 안 브라우저 | | |
| 4 | 안드로이드 | 크롬 또는 삼성 인터넷 | | |
| 5 | 어르신 휴대폰 (글자 크게 설정) | 카톡 안 브라우저 | | |

## 항목

| # | 확인할 것 | 기대 결과 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|---|
| 1 | 카톡으로 받은 초대 링크 열기 | 초대 화면이 뜬다. 뒤 4자리 입력 후 연결 | | | | | |
| 2 | 카카오 로그인 (방식 2) | 카톡 앱으로 넘어갔다가 돌아와 로그인됨. 원래 보던 화면으로 복귀 | | | | | |
| 3 | 메일 코드 로그인 | 코드 메일이 1분 안에 온다. 휴대폰 키보드에 코드 자동 제안(아이폰) | | | | | |
| 4 | 카톡 안에서 로그인 실패 시 | "브라우저로 열기" 안내가 보이고 눌러서 외부 브라우저가 열린다(안드로이드) | | | | | |
| 5 | 영수증 사진 찍기 | [영수증 사진 넣기] → 카메라 선택 → 찍으면 바로 올라가고 썸네일이 보인다 | | | | | |
| 6 | 앨범에서 사진 고르기(아이폰 HEIC) | JPEG로 바뀌어 올라간다. 실패하면 "높은 호환성" 안내 | | | | | |
| 7 | PDF 영수증 | 파일 앱에서 골라 올라간다 | | | | | |
| 8 | 사진 확대 | 썸네일을 누르면 같은 창에서 크게 열리고 뒤로 가기로 돌아온다 | | | | | |
| 9 | 글자 크게 설정 | 버튼 글자가 잘리지 않고 가로 스크롤이 없다 | | | | | |
| 10 | 작성 중 앱 전환 | 사진 찍으러 갔다 와도 적은 내용이 남아 있다 | | | | | |
| 11 | 저장 안 하고 나가기 | "나가시겠습니까" 경고가 뜬다(카톡 안에서는 안 뜰 수 있음, 메모) | | | | | |
| 12 | 결재 올리기 | "결재 중"이 되고 부장에게 메일이 간다 | | | | | |

| 14 | 승인 후 화면 | "승인하셨습니다 · ○○님께 메일로 알렸습니다"가 남아 있다 | | | | | |
| 15 | [사무실에 전화] 버튼 | 전화 앱이 사무실 번호로 열린다 | | | | | |

## 통과 기준

- 1~3, 5, 12~14는 모든 기기에서 O여야 시범 운영을 시작한다.
- 나머지 X는 원인과 우회 방법을 적고, 시범 운영 안내문에 넣는다.
